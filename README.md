# Projet DevOps — Master 2

## 1. Présentation

Ce projet a pour objectif de mettre en pratique les principes et outils DevOps
dans le cadre d'un environnement virtualisé sous Ubuntu avec VMware.

Il s'appuie sur une API Python de démonstration qui sera progressivement
intégrée dans un processus automatisé de développement, de test et de déploiement.

## 2. Objectifs

- Versionner le code source avec Git et GitHub.
- Développer une API Python.
- Automatiser les tests avec Pytest.
- Conteneuriser l'application avec Docker.
- Orchestrer les services avec Docker Compose.
- Automatiser l'intégration et le déploiement continus avec GitHub Actions.
- Publier les images Docker sur GitHub Container Registry (GHCR).
- Analyser les vulnérabilités avec Trivy.
- Étudier la supervision et la sécurité avec Zabbix, Wazuh et pfSense.

## 3. Technologies

- Ubuntu
- Git et GitHub
- Python
- Pytest
- Docker et Docker Compose
- GitHub Actions
- GitHub Container Registry (GHCR)
- Trivy
- Zabbix
- Wazuh
- pfSense

## 4. Environnement de travail

Le projet est réalisé dans une machine virtuelle Ubuntu exécutée sous VMware.
